# Wave Implementation Skill

1. Read all plan files and current project status
2. Identify the next unimplemented wave
3. Break it into parallel-safe task groups
4. Write the wave plan to plans/wave_N.md
5. Ask user to confirm, then begin implementation using Task agents for parallelism
6. After each file is written, run a smoke test if one exists
7. Verify all state flags (_loaded, _initialized, etc.) are properly set
